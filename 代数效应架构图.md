## 详细执行流程

```mermaid
sequenceDiagram
    participant Program as 程序
    participant PushHandler as EffectPushHandler
    participant Stack as Effect Stack
    participant Perform as EffectPerform
    participant Handler as Handler
    participant Resume as EffectResume
    participant PopHandler as EffectPopHandler
    
    Program->>PushHandler: 1. 注册Handler
    PushHandler->>Stack: 2. 分配32字节栈帧
    PushHandler->>Stack: 3. 保存prev_effect_head
    PushHandler->>Stack: 4. 设置tag和handler_label
    PushHandler->>Stack: 5. 更新effect_head
    
    Program->>Perform: 6. 执行Effect
    Perform->>Stack: 7. 遍历effect_head链表
    alt 找到匹配的Handler
        Perform->>Handler: 8a. 跳转到Handler
        Handler->>Resume: 9a. 调用EffectResume
        Resume->>Program: 10a. 返回到resume_label
    else 未找到Handler
        Perform->>Program: 8b. 跳转到unhandled
    end
    
    Program->>PopHandler: 11. 弹出Handler
    PopHandler->>Stack: 12. 恢复prev_effect_head
    PopHandler->>Stack: 13. 释放栈帧
```

## 链表遍历逻辑

```mermaid
flowchart TD
    Start([开始遍历]) --> Init[初始化walker = effect_head]
    Init --> Check{walker == 0?}
    Check -->|是| Unhandled[跳转到unhandled]
    Check -->|否| LoadTag[加载walker.tag]
    LoadTag --> Compare{tag匹配?}
    Compare -->|是| Found[找到Handler]
    Compare -->|否| Next[walker = walker.prev]
    Next --> Check
    Found --> SetResume[设置resume_label]
    SetResume --> Jump[跳转到Handler]
    Jump --> Resume[Handler执行]
    Resume --> Return[返回到resume_label]
```

## 关键特性说明

- **单向链表结构**: 通过prev_effect_head字段构建Handler栈
- **动态标签匹配**: 支持静态和动态tag匹配
- **尾调用优化**: Handler跳转使用tail jump
- **栈帧管理**: 统一的32字节栈帧布局
- **错误处理**: 未找到Handler时的unhandled处理
